# homeless-shelter

A rudimentary attempt at configuring my systems, rough edges included.

### Disclaimer

I've worked on my config without consideration that it will be read/studied
except for keeping the code clean; i.e., my config is spread out without any
explanation for why things are the way the are. This `README` also exists
solely to express gratitude towards people who've helped shape it.

That said, you're welcome to reference it as you like.
